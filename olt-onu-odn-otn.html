光接入网 · 设备辨析

OLT、ONU、ODN
为什么是接入产品，而 OTN 通常不是？

一道选择题背后，是光网络“接入”与“传送”两个层次的分工逻辑。

原题回顾

下列设备形态属于接入产品的是哪些？

ODN ✓ ONU ✓ OTN OLT ✓
✓ 正确答案：ODN、ONU、OLT

OTN 的底色是“传送网”，通常不算标准接入产品。只有被专门标注为“接入型 OTN”的设备，才在部署形态上扮演接入角色。

1

核心线索：PON 的三元结构

OLT、ODN、ONU 之所以被归为接入产品，不是因为它们各自孤立存在，而是因为它们共同构成了一套完整的光接入系统——PON（无源光网络）。

PON 是“点到多点”的光接入系统：OLT 在局端，ODN 在中间做无源分光，ONU 到用户侧。

局端

OLT：接入网的“局端锚点”

部署在运营商机房，是 PON 协议在局端的终结点，负责汇聚众多用户流量并向上连接到城域网。华为官方将其归入“接入网”产品线[reference:0]。

用户侧

ONU：接入网的“用户门户”

部署在用户家中或企业内，把光纤中的光信号转换成电信号，提供以太网、语音等用户接口。它就是普通人熟悉的“光猫”的专业名称。

中间层

ODN：接入网的“无源骨架”

由光纤、光分路器、光交接箱等无源器件组成，不含任何有源电子设备。它的“无源”属性是 PON 区别于有源接入的本质特征[reference:3]。

2

判定标准：它们在网络中“站什么位置”

接入产品的本质，是位于用户与运营商网络之间的“最后一公里”基础设施。OLT、ONU、ODN 三者合在一起，恰好完整覆盖了这一段。

设备部署位置在 PON 中的角色为什么是接入产品
OLT 运营商局端机房（中心局 / 接入机房） PON 的局端终结点，汇聚用户流量并向上连接城域网 它是“用户侧到网络侧”的接入汇聚边界，华为接入网产品线明确包含 OLT[reference:5]
ONU 用户家中、企业内或楼宇侧 PON 的用户侧终结点，提供用户接口 直接面向最终用户，是接入网在用户端的落地设备
ODN OLT 与 ONU 之间的光缆线路与分光设施 提供 OLT 与 ONU 之间的无源光通道 不包含有源设备，是接入网专有的无源基础设施

OLT、ODN、ONU 合起来正好占据“接入网”这一段；再往右，就进入传送与汇聚的地盘。

3

OTN 为什么通常不算：它的底色是“传送”

OTN（光传送网）与 OLT/ONU 并不在同一张“用途地图”上。OTN 的核心使命是大带宽、长距离的传送与承载，传统定位在骨干层和城域汇聚层。

OTN（标准定位）

  • 属于传送网技术，主要应用于骨干层和城域网[reference:9]。
  • 解决的是“把大量流量从 A 传送到 B”的问题。
  • 与 OLT/ONU 的“用户接入”使命不在同一层次。

接入型 OTN（例外）

  • 是功能简化的 OTN 设备，被下沉部署到接入汇聚层或客户端[reference:10]。
  • 用于政企专线等场景，在部署形态上扮演“接入”角色。
  • 但它是“OTN 技术向接入侧的延伸”，而不是 OLT/ONU 那类原生接入产品。
一句话记住区别：OLT、ONU、ODN 是接入网的“原住民”；OTN 是传送网的“原住民”，只有当它被特意做成“接入型 OTN”并下沉到边缘时，才临时扮演接入角色。题目问的是标准接入产品，所以 OTN 不在答案里。
4

速查：四个设备的归属

做分类题时，抓住“接入网原生”这个关键词就够了。

设备技术归属典型部署位置属于接入产品？
ODN PON 无源光分配网络 OLT 与 ONU 之间的线路与分光设施 是
ONU PON 用户侧终端 用户家中 / 企业内 是
OLT PON 局端汇聚设备 运营商接入机房 / 中心局 是
OTN 光传送网 骨干层 / 城域汇聚层（标准形态） 否（标准形态） 接入型 OTN 例外

OLT 的实物印象

通常是机房里的机架式设备，插板式结构，面板上密集排列着光纤接口。你家的“光猫”最终汇聚到它这里。

ONU 的实物印象

就是普通人家里那个带几根天线或几个网口的小盒子——“光猫”。它把光纤信号转换成 Wi-Fi 或网线信号供设备使用。

ODN 的实物印象

不是一台“设备”，而是一整套无源设施：楼道光交箱、路边分纤箱、 ceiling 里的分光器、以及连接它们的光缆。
